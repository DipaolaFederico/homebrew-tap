# DipaolaFederico/homebrew-tap

Homebrew formula for [kmd](https://github.com/DipaolaFederico/kmd), a fast Markdown previewer for the terminal.

```sh
brew install DipaolaFederico/tap/kmd
```

`Formula/kmd.rb` is updated by the kmd release workflow on every release; do not edit it by hand.
Issues: <https://github.com/DipaolaFederico/kmd/issues>.
